# 能力（skill）调度建议

## 使用前提

1. 先看当前环境实际可用的能力，不要凭记忆报名字；名称与可用性随环境变化。
2. 能力只补工具与数据源，不替流程、不替判断。
3. 每次调用都要留证：命令、退出码、输出文件、哈希。留不了证的能力不纳入流水线。
4. 兜底型能力默认关闭，只在前置手段拿不到关键证据时启用。

## 按阶段选能力

| 阶段 | 能力类型 | 解决什么 | 证据 | 何时不用 |
| --- | --- | --- | --- | --- |
| 定位 | 对标/榜单/账号分析类 | 拆解对标的内容结构 | 分析记录 + 来源链接 | 用户没给对标对象 |
| 取证 | 行情与财务数据类 | 拉原始数值 | 命令 + 退出码 + 输出文件 + 哈希 | 标的不在覆盖范围 |
| 取证 | 产业环节梳理类 | 建产业链骨架 | 同上 | 题材非产业驱动 |
| 取证 | 学术/论文/专利类 | 查定义、指标、路线 | 同上 | 题材无学术文献 |
| 取证 | 通用联网检索/深度研究类 | 找公开来源与背景 | 同上 | 已有结构化数据源 |
| 取证 | 网页抓取/浏览器类（兜底） | 读动态页、被拦截页 | URL + 标题 + 日期 + 统计期 + 提取字段 + 采集时间 | 默认关闭 |
| 呈现 | 图片生成/搜图类 | 补示意图、封面 | 生成记录 + 版权/水印检查 | 有真实资料图时优先真实图 |
| 构建 | 文档/表格/幻灯片类 | 产出交付件 | 文件路径 + 校验结果 | 只需网页成品时 |
| 交付 | 平台排版类 | 生成平台兼容成品 | 渲染报告 | 无对应平台时 |
| 复盘 | 发布数据复盘类 | 报表解析与诊断 | 报告 md + json + 台账变更 | 数据未导出 |

## 选题类型 → 能力组合

| 选题类型 | 首选 | 次选 | 兜底 |
| --- | --- | --- | --- |
| 产业 / 上市公司 | 行情财务数据类 + 公告原文 | 产业环节梳理类 | 浏览器类 |
| 政策 / 宏观 | 官方文件与统计原文 | 联网检索类 | 浏览器类 |
| 技术 / 学术 | 论文/专利检索类 | 联网检索类 | 浏览器类 |
| 消费 / 产品 | 公开评测与价格页 | 搜图类 | 浏览器类 |
| 教程 / 方法论 | 自有文档与案例 | 文档生成类 | 不需要 |

## 固定顺序

把顺序写进 `docs/skill_plan.md`，按证据强度递减：

**结构化数据源 → 官方原文 → 常规公开资料 → 浏览器兜底**

规则：

- 前一档没跑完，不许跳到后一档；
- 前一档明确 `not_applicable` 才可跳过，并写理由；
- 不适用不是失败，但必须留痕，否则门禁分不清"没做"和"不需要做"。

## 不该用能力的情况

- 规则还在探索期，产出无法稳定复现；
- 调用结果无法留证；
- 想用它直接生成正文结论——起草可以，事实必须回台账；
- 想用它替代你该做的判断（定题、取舍、结论、发布）。

## 复盘类能力的边界

只产出诊断与建议，不自动改选题档位、不自动改门禁阈值。改哪条、改到什么值，由人拍板。

## 写进调度表的字段

```yaml
- stage: 取证
  capability: <实际名称>
  purpose: <一句话>
  evidence: [command, exit_code, output_file, sha256]
  fallback: true | false
  not_applicable_when: <条件>
```
